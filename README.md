# 芸编 Folio

一个**本地优先**的藏书管理应用(macOS)。

扫码/手输/NFC 三通道录入、三级元数据自动补全(豆瓣 → Open Library → Google Books)、三栏书架、借阅与阅读闭环、WebDAV 多端同步(坚果云等)。

> **本仓库为安装包发布仓库,不含源代码。** 源码位于私有仓库 `ZhengBo1011/Yunbian-Folio-Source`。

## 下载

前往 [Releases](../../releases) 页面下载最新公测版安装包:

| 文件 | 说明 |
|---|---|
| `Folio-v0.2.1-build10.dmg` | 磁盘映像安装包(推荐) |
| `Folio-v0.2.1-build10.zip` | 压缩包版 |

## 系统要求

- macOS 14.0 及以上
- Apple Silicon (arm64)

## 安装

1. 下载 DMG(或 ZIP)
2. 打开 DMG,将「芸编」拖入 Applications 文件夹
3. 首次运行:如出现钥匙串授权弹窗,点「始终允许」(仅此一次,之后同一签名版本不再弹出)

## 更新日志

### v0.2.1 — 公测版 (build 10)

- **界面打磨**:侧栏「借出中」图标修复;顶栏紧凑排布(排序菜单首位)
- **设置中心**:主题切换(跟随系统/浅色/深色);阅读状态/评分开关(数据保留,重开即恢复);5 种阅读状态词条自定义;副本默认按位置命名
- **相机权限重写**:点击「相机扫码」前台先申请权限,拒绝/受限时就地引导系统设置
- **列表与副本**:列表行高固定修复重叠;副本行删除入口(软删);读书笔记 1000 字实时计数
- 同步协议零改动,WebDAV 同步不受影响

### v0.2.0 — 内测版 (build 4)

- 检索扩展:搜索覆盖标签/分类/笔记/阅读状态;六种排序
