# 芸编 Folio

一个**本地优先**的藏书管理应用。

扫码/手输/CSV 三通道快速录入,三级元数据自动补全(豆瓣 → Open Library → Google Books),三栏书架组织藏书,完整的阅读/借阅/笔记闭环,WebDAV 多端同步——数据始终保存在你自己手里。

**当前平台**:macOS 原生版(Swift/SwiftData)。
**多端路线**:鸿蒙版(ArkTS)开发推进中,后续规划 Android、iOS、Windows、Linux 版本;多端数据通过 WebDAV 保持同步更新。

---

## ✨ 功能与特色

### 📚 书库管理

- **三栏书架**:侧栏分组(全部藏书/标签/馆藏位置)+ 列表 + 详情,信息密度对齐桌面端
- **三通道录入**:
  - 相机扫码:实时识别图书 ISBN(权限前置申请,拒绝时就地引导)
  - 手动输入:书名/作者/ISBN 手工录入,自动补全
  - CSV 批量导入:19 列完整模板,解析预览 → 确认入库,失败行号报告
- **三级元数据自动补全**:豆瓣 → Open Library → Google Books 降级链,识别命中自动填充空缺字段;支持手动刷新与元数据锁定
- **完整书目字段**:书名/副书名/作者/编者/译者/出版社/出版地/出版年/分类/页数/封面/来源
- **分类与标签**:自定义分类、标签、馆藏位置(自动建档),侧栏点击即过滤
- **副本管理**:一本书多个副本,品相/存放位置/电子版格式/价格/购入日期/PDF 备注/自定义字段;副本默认按位置命名;支持副本删除(软删)
- **ISBN 防重**:库内活书 + 批量导入行间查重

### 📖 阅读闭环

- **阅读状态**:想读 / 在读 / 读完 / 搁置 / 弃读,5 种状态词条可自定义(留空回退默认)
- **阅读进度**:页码/百分比记录,起读/读完/最近阅读时间自动打点
- **评分**:1–5 星,列表行直接显示
- **读书笔记**:笔记关联具体副本,1000 字实时计数,占位文案引导
- **状态开关**:阅读状态/评分可一键隐藏显示(数据保留,重开即恢复)

### 📤 借阅闭环

- 借出:选择借阅人 + 日期,一键借出
- 归还:一键清空借阅状态
- 借出中状态展示(借出给 XX · 日期)+ 侧栏「借出中」过滤与计数

### 🔐 数据安全

- **JSON 全量备份 / 恢复**:恢复前自动备份当前库(回滚保险),幂等写入
- **CSV 导出**:19 列完整模板(含副本联查/阅读状态/评分/进度),向后兼容
- **软删除 + 同步墓碑**:删除可追溯,不影响多端同步

### 🔄 多端同步

- **WebDAV 同步**:坚果云等标准 WebDAV 服务,增量同步 + 冲突合并 + 设备身份
- 快照化同步管线,备份/恢复与同步同构,幂等可靠

### 🔍 检索与排序

- **全局搜索**:书名/作者/ISBN/标签/分类/笔记内容/阅读状态
- **六种排序**:最近更新 / 书名 / 作者 / 出版年 / 评分 / 最近阅读

### 🎨 界面与体验

- **主题切换**:跟随系统 / 浅色 / 深色
- 顶栏紧凑排布,常用操作一键直达
- 键盘快捷键:⌘N 录入、⌘F 搜索、Esc 关闭浮层
- 列表/详情流畅滚动,批量操作不卡顿

## 系统要求

- macOS 14.0 及以上
- Apple Silicon (arm64)

## 安装

1. 前往 [Releases](../../releases) 下载最新版 DMG(或 ZIP)
2. 打开 DMG,将「芸编」拖入 Applications 文件夹
3. 首次运行:如出现钥匙串授权弹窗,点「始终允许」(仅此一次,之后同一签名版本不再弹出)
