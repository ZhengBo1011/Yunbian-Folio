# 芸编 Folio · Yunbian Folio

一个**本地优先**的藏书管理应用。

扫码/手输/CSV 三通道快速录入，三级元数据自动补全（豆瓣 → Open Library → Google Books），三栏书架组织藏书，完整的阅读/借阅/笔记/书单闭环，WebDAV 多端同步——数据始终保存在你自己手里。

**当前平台**：macOS 原生版（Swift/SwiftData），**v1.0.0 正式版**。
**多端路线**：鸿蒙版（ArkTS）开发推进中，后续规划 Android、iOS、Windows、Linux 版本；多端数据通过 WebDAV 保持同步更新。

## ✨ 功能与特色

### 📚 书库管理

- **三栏书架**：侧栏分组（全部藏书/标签/馆藏位置）+ 列表 + 详情，信息密度对齐桌面端
- **三通道录入**：
  - 相机扫码：实时识别图书 ISBN（权限前置申请，拒绝时就地引导）
  - 手动输入：书名/作者/ISBN 手工录入，自动补全
  - CSV 批量导入：24 列完整模板，解析预览 → 确认入库，失败行号报告
- **三级元数据自动补全**：豆瓣 → Open Library → Google Books 降级链，识别命中自动填充空缺字段；支持手动刷新与元数据锁定
- **完整书目字段**：书名/副书名/作者/编者/译者/出版社/出版地/出版年/分类/页数/封面/来源
- **分类与标签**：自定义分类、标签、馆藏位置（自动建档），侧栏点击即过滤
- **副本管理**：一本书多个副本，品相/存放位置/电子版格式/价格/购入日期/PDF 备注/自定义字段；副本默认按位置命名；支持副本删除（软删）
- **ISBN 防重**：库内活书 + 批量导入行间查重
- **愿望清单**：待购书独立视图，购买后一键转正入藏

### 📊 书库统计

- **八大维度图表**（Swift Charts）：总览指标 / 分类 Top 10 / 出版年代分布 / 出版社 Top 10 / 评分分布 / 阅读状态占比 / 藏书位置 / 入库节奏折线
- **AI 分析卡位**：即将上线，将基于当前书库一键生成阅读报告（协议已预留）

### 📑 书单（收藏体系）

- **主题化收藏**：如「2026 私藏书」「送朋友的入门书」，卡片封面取最早加入的书
- **批量添加**：从藏书或愿望清单多选加入；条目保留加入时间
- **删除安全**：删除书单不影响书目本体（仍保留在藏书/愿望清单）

### 📖 阅读闭环

- **阅读状态**：想读 / 在读 / 读完 / 搁置 / 弃读，5 种状态词条可自定义（留空回退默认）
- **阅读进度**：页码/百分比记录，起读/读完/最近阅读时间自动打点
- **评分**：1–5 星，列表行直接显示
- **读书笔记**：笔记关联具体副本，1000 字实时计数，占位文案引导
- **状态开关**：阅读状态/评分可一键隐藏显示（数据保留，重开即恢复）

### 📤 借阅闭环

- 借出：选择借阅人 + 日期，一键借出
- 归还：一键清空借阅状态
- 借出中状态展示（借出给 XX · 日期）+ 侧栏「借出中」过滤与计数

### 🔐 数据安全

- **JSON 全量备份 / 恢复**：含全部 9 类实体（藏书/副本/位置/标签/笔记/阅读记录/评分/选项/书单）+ 设置偏好；恢复前自动备份当前库（回滚保险），幂等写入
- **完整数据包（ZIP）**：library.json + library.csv + notes.json + booklists.json + 说明，一键导出/导入，适合整库归档与跨设备搬迁
- **CSV 导出/导入**：24 列完整模板（含馆藏状态/标签/阅读状态/评分/进度），向后兼容旧模板
- **笔记/书单独立备份**：结构化 JSON，可回导合并（新者胜 + 墓碑优先），笔记未匹配书目跳过并报告
- **顶栏快捷导出**：当前视图 CSV / 读书笔记 Markdown 一键导出
- **软删除 + 同步墓碑**：删除可追溯，不影响多端同步

### 🔄 多端同步

- **WebDAV 同步**：坚果云等标准 WebDAV 服务，增量同步 + 冲突合并 + 设备身份
- 快照化同步管线（协议 v1.2），备份/恢复与同步同构，幂等可靠
- 同步覆盖全部业务数据；外观等设备偏好不参与双端合并（各设备独立）

### 🔍 检索与排序

- **全局搜索**：书名/作者/ISBN/标签/分类/笔记内容/阅读状态
- **九种排序**：最近更新 / 书名 / 作者 / 出版年 / 评分 / 最近阅读等
- **筛选条**：标签/位置一键筛选，ISBN 容错检索
- **笔记导出**：读书笔记 Markdown 一键导出

### 🎨 界面与体验

- **主题切换**：跟随系统 / 浅色 / 深色，切换即时生效
- **封面管道**：豆瓣防盗链修复 + 两级缓存，封面加载更稳
- **位置图标**：18 枚馆藏位置图标自选
- 顶栏紧凑排布，常用操作一键直达；书单/统计页顶栏按钮按上下文自动置灰
- 顶栏「同步」按钮：关闭自动同步后仍可一键手动同步
- 键盘快捷键：⌘N 录入、⌘F 搜索、Esc 关闭浮层
- 自适应文本显示：列表/详情窄栏自动降级（书名优先、次要信息隐藏），藏书信息单行横滚 + 右缘渐隐
- 列表/详情流畅滚动，批量操作不卡顿

### 🔮 软件开发规划

- **多设备同步上线**：鸿蒙端与 macOS 端经 WebDAV 双向同步打通后正式发布，后续 Android / iOS / Windows 接入同一同步协议，任何设备改动全端收敛
- **PDF 电子书阅读与管理**：电子版藏书从「格式备注」升级为「可阅读资产」——PDF 导入书库、内置阅读器、阅读进度与笔记联动、按副本/位置管理电子书文件
- **AI 阅读分析**：基于当前书库一键生成阅读报告与结构总结（统计页卡位已预留）
- **封面旁路云存储**：封面经 WebDAV 独立目录同步，减少快照体积
- 持续打磨：更多统计维度、批量管理工具、国际化

## 系统要求

- macOS 14.0 及以上
- Apple Silicon (arm64)

## 安装

1. 前往 [Releases](../../releases) 下载最新版 DMG（或 ZIP）
2. 打开 DMG，将「芸编」拖入 Applications 文件夹
3. 首次运行：如出现钥匙串授权弹窗，点「始终允许」（仅此一次，之后同一签名版本不再弹出）
